This console talks directly to the coordinator's HTTP API (/nodes, /submit_training_job, /training_status/<id>, /training_jobs/<id>/weights) from the browser — the same calls run_weight_jobs.py makes. It fetches strawberry_dataset.zip itself, so there's nothing to upload. No training or evaluation logic runs here or was altered; if the coordinator doesn't send CORS headers, or doesn't serve strawberry_dataset.zip over HTTP, those requests will fail and the error banner above the Compare button will say so.
